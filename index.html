Space QR Scanner (GitHub Pages)

Halaman ini menggunakan kamera browser untuk memindai QR. GitHub Pages menyediakan HTTPS sehingga getUserMedia boleh bekerja. Jika kamera tidak tersedia, gunakan input manual.

Klik "Start" untuk mengaktifkan kamera
Hasil scan:
Jika tombol "Buka ke Halaman Login" tidak cocok, salin kode dan tempel ke form login lokal Anda.
Masukkan kode secara manual
Catatan: tombol "Buka ke Halaman Login" akan menambahkan parameter `username` dan `password` ke URL, keduanya diisi kode hasil scan (sesuaikan jika sistem Anda berbeda).
